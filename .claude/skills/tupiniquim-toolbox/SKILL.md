# Tupiniquim Company Toolbox

Use esta skill quando estiver trabalhando em qualquer projeto da Tupiniquim, especialmente para planejamento, auditoria, implementação, revisão, segurança, UI/UX, automação ou escolha de ferramentas.

## Fontes

Leia antes de decidir:
- `docs/AI_TOOLBOX/REPOSITORIES.md`
- `docs/AI_TOOLBOX/SECURITY_BASELINE.md`
- `docs/AI_TOOLBOX/VIDEO_CHECKLISTS_2026-09-03.md`

## Fluxo

1. Investigue o repositório e confirme o estado real.
2. Classifique o pedido: UI/UX, segurança, prompt, pesquisa, automação, IA generativa, voz, agente/RAG ou infraestrutura.
3. Consulte somente as referências relevantes do catálogo.
4. Não copie código externo cegamente. Verifique licença, dependências, manutenção, riscos e compatibilidade.
5. Preserve arquitetura e escopo do projeto.
6. Para mudanças de código, aplique a baseline de segurança e execute os checks existentes.
7. Converta achados em issues pequenas, verificáveis e priorizadas.
8. Antes de concluir, registre: arquivos alterados, testes executados, riscos restantes, referência externa usada e próximo passo.

## Roteamento rápido

- UI/UX → UI UX Pro Max.
- Prompts → Prompt Master.
- Pesquisa/web/social → Agent Reach.
- Pentest autorizado → Strix.
- Software agent-native/CLI → CLI-Anything.
- Agentes/RAG → Awesome LLM Apps.
- Instagram automation → OpenReply.
- TTS local → Pocket TTS.
- Mídia generativa → Open Generative AI.
- Pesquisa de inferência local extrema → kimi-k3-in-c.

## Limites

- Nunca exponha secrets.
- Nunca teste alvo de terceiros sem autorização.
- Não execute migração destrutiva, force-push, exclusão, publicação externa, compra ou alteração de dados reais sem autorização explícita.
- Não ampliar escopo apenas porque uma referência externa contém mais funcionalidades.
