# Projeto

## Produto

Tupiniquim AI Dev Studio é uma plataforma privada, local-first e desktop-first para engenharia de software agêntica generalista. Ela deve planejar, pesquisar, implementar, testar, revisar e recuperar trabalhos reais em projetos WEB, DESKTOP e MOBILE.

## Resultado da auditoria

- Alvo aprovado: `F:\CODEX\Tupiniquim-AI-Dev-Studio`.
- Dados locais: `F:\CODEX\Tupiniquim-AI-Dev-Studio.data`.
- Os demais diretórios de `F:\CODEX` pertencem a outros projetos e não podem ser reutilizados nem alterados.
- Ambiente: Windows 10 x64, 4 processadores lógicos, NTFS, WebView2 e runtime Node 24 preexistente.
- Ausentes na auditoria inicial: Rust, .NET SDK, Docker, ADB e Visual Studio Build Tools.
- A distribuição V1 é Windows x64 portátil. A arquitetura permanece portável.

## Usuário e experiência

O usuário principal é um desenvolvedor que quer uma estação privada com controles explícitos, evidência verificável e autonomia graduada. O produto começa em PT-BR e evita exigir conhecimento prévio da implementação interna.

## Princípios

1. Segurança e integridade antes de autonomia.
2. Estado, plano, aprovações e evidências são duráveis.
3. Resultados reais substituem demos ou simulações.
4. O núcleo é um monólito modular com adapters substituíveis.
5. A interface revela complexidade progressivamente.
6. Nenhum provedor ou stack é fixo fora de um adapter.
